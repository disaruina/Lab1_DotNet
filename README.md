## Ответы на контрольные вопросы

### 1. Чем Console.Write() отличается от Console.WriteLine()?
`Console.Write()` выводит текст на экран и оставляет курсор на той же строке (следующий вывод продолжится сразу за текстом). 
`Console.WriteLine()` выводит текст и автоматически переносит курсор на новую строку.

### 2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?
Произойдет ошибка компиляции (Compile-time error): *"Cannot implicitly convert type 'double' to 'int'"*. Поскольку C# — язык со статической типизацией, компилятор запрещает автоматическую потерю точности без явного приведения типов.

### 3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?
При делении двух целых чисел (`int / int`) в C# всегда происходит целочисленное деление, а дробная часть просто отбрасывается. Чтобы получить дробный результат, нужно привести хотя бы один из операндов к типу `double`, например: `(double)10 / 3` или написать `10.0 / 3`.

### 4. Что означает var в C#? Чем он отличается от динамической типизации в Python?
Ключевое слово `var` включает **неявную типизацию** (Type Inference) — компилятор сам определяет тип переменной в момент компиляции по значению справа. Однако, в отличие от динамического Python, переменная с ключевым словом `var` остается строго типизированной. Изменить её тип во время выполнения программы нельзя.
